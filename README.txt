Campus Connect 2026 — College Event Registration Website

Files to upload to a GitHub repository:
- index.html
- styles.css
- app.js

After uploading, use GitHub repository Settings > Pages, choose "Deploy from a branch",
then select the main branch and the /(root) folder. GitHub will provide a public link.

This static version saves registrations only in the browser used to submit the form.
For real registrations shared with organizers, connect the form to a secure backend,
Google Form, or form service before publishing.
